# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

uzume-plugin-randomizer is the official Randomizer plugin for Uzume. It holds the presets (settings strings for the randomizer engine), the Randomize dialog on the game page, the Randomizer section of New run (each person gets their own variant, or the same world for everyone), the list of the user's own variants and the spoiler log on request. It does not randomize anything itself: it hands a recipe (engine version, settings, seed) to Uzume, which builds the variant on the user's PC with the engine from the server's tools catalog.

## Relation to Uzume

- Plugin for [Uzume](https://github.com/phabioo/uzume) (self-hosted retro gaming platform). Decision record: `docs/adr/0031-game-variants-and-randomizer.md`; design: `docs/design/uzume/randomizer.md` (sheet 5, boards 10a to 10h); plugin interface: `docs/architecture/12-plugins.md` and `docs/guides/plugin-api.md`, all in the Uzume repository.
- Needs Uzume 0.22: game variants, the tools catalog and the variant build permission are not built yet; everything here is design until they exist. Open API items are marked open, never invented.
- Runtime: Lua 5.4 in the Uzume sandbox; UI only as declarative building blocks (no QML). No sidebar row: the UI lives on the game page and in New run.
- Engine: Universal Pokémon Randomizer FVX (GPL-3.0). It is never checked into this repository; the Uzume server downloads and pins it.

## Working rules

- Repository language is English: code, comments, UI strings, docs, commit messages and PRs.
- Opus only orchestrates and writes no product code; implementation is done by the Sonnet 5.5 agents in `.claude/agents/`, searching and log reading by the Haiku agent `scout` (alias `haiku`).
- Briefs follow the template in `docs/workflow.md` (which also holds the token-saving rules).
- Opus verifies via `git diff --stat`, a targeted diff and the test result; commit/PR by Opus. One work package per thread, one topic per PR.

## Hard rules

- No ROMs, BIOS, firmware, game files, randomized outputs, patches, LayeredFS folders, spoiler logs, extracted assets or dumps of real games in the repository or in tests. Tests use only synthetic data generated by code.
- No randomizer engine binaries or jars in the repository.
- Spoilers stay hidden: the plugin never shows what was randomized; the spoiler log is off by default, opens only on request after a confirm, and for run variants only after the run ends and only the own one. Error details carry no creature, item or trainer names.
- Nintendo/Pokémon names may appear as text identifiers only.
- Never put secrets in files, profiles or logs.
- Never overwrite saves silently; every variant plays in its own slot and Main is never touched.

## Languages

- Target versions are the German/EU releases first; presets must work for at least German and English versions of each game.
- Plugin UI strings come from i18n files (`i18n/`): English is the source, German the first translation.
